Fallet for macOS

Requires macOS 13 or later. Works on Apple silicon and Intel Macs.

INSTALL
1. Drag Fallet.app onto the Applications shortcut in this window.
2. Eject the Fallet disk image.
3. Open Fallet from Applications. Its icon appears in the menu bar.

The release is signed with an Apple Developer ID and notarized by Apple.
If macOS reports that this copy cannot be opened, download the latest release
again from the project's GitHub Releases page. Do not disable Mac security.
